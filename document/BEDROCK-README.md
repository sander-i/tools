# 基础包

----

目录:

* annotations 注解
* base 基础对象
    * serializable 序列化基础对象
* constant 常量
* database 数据库
    * mysql
    * oracle
    * sqlserver
* definer 定义
* exception 异常
* factory 工厂
* http 请求
    * mysql
    * oracle
    * resp
* uniqueid 唯一id
    * snowflake 雪花id
    * tddl
    * uuid
* util 工具
    * date 时间工具
    * file 文件工具
    * network 网络工具

## exception 异常

1. BaseException 抽象异常类
2. BusinessException 业务异常类
3. ErrorException 错误异常类
4. ToolsException 工具异常类

3. BaseUtils 基础工具
4. BigDecimalUtils BigDecimal工具
5. ClassUtils 类工具
6. CopyUtil 拷贝工具
7. FeatureUtil 特征工具
8. JsonUtil Json工具
9. Lists 集合工具
10. Maps Map工具
11. TransformUtils 转换工具
