## Project History

The project has been in development since 2023 and has gone through several rounds of iteration
and optimization:

### 2023
- Project initialization
- Base module development (`bedrock`, `encrypt`, `fortify`)
- Releases 1.0.0 - 1.0.3

### 2024
- Feature module expansion
- Utility optimization and refactoring
- Releases 1.0.4 - 1.0.6.2

### 2025
- Encryption module upgrade
- Image utility module optimization
- Spring Boot Starter integration
- Releases 1.0.6.3 - 1.0.6.6

### 2026
- Open source compliance documents added
- Full image utility optimization
- 2.0.0 release in preparation

## How to Add Your Name

If you have contributed to this project (code, documentation, tests, bug reports, etc.), you are
welcome to add your name to this file in a Pull Request.

Please follow this format:

```markdown
## Contributors

- **Your Nickname** (email optional)
  - Brief description of your contribution
```

## Types of Contributions

We welcome the following types of contributions:

- Code contributions (new features, bug fixes, optimizations)
- Documentation improvements (README, Wiki, comments)
- Test coverage (unit tests, integration tests)
- Issue reporting (bug reports, feature suggestions)
- Code review (Pull Request reviews)
- Community support (helping other users)
